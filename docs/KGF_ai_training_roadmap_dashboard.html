90-day execution

훈련에서 PoC까지의 실행 흐름

각 단계는 완료 기준을 확인하고 다음 단계로 이동합니다.

DAY 0–30

문제와 데이터를 정한다

  • P1 과제와 사용자 확정
  • As-Is 업무 흐름 작성
  • 샘플 데이터·보안등급 확인
  • 입력항목·코드·책임자 정의
DAY 31–60

작은 화면으로 검증한다

  • 표준 양식 시범 운영
  • 노코드·바이브코딩 PoC 초안
  • 입력 누락·오류 점검
  • 사용자 테스트와 개선
DAY 61–90

성과를 측정하고 결정한다

  • PoC 반복 사용
  • 업무시간·오류·지연 전후 비교
  • 확산 또는 보완안 검토
  • 다음 DX·AX 후보 선정
Meeting checklist

2차 컨설팅 종료 전 6가지 합의

  • 첫 PoC 과제 1건을 선택한다.
  • 데이터 항목별 책임자와 입력 주기를 정한다.
  • 표준 양식의 시작일과 사용자 범위를 정한다.
  • 사용자 테스트 기준과 KPI를 정한다.
  • GPT Business 입력 가능·금지 정보의 승인자를 정한다.
