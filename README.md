# 케이지에프 AI 훈련컨설팅 · 기업소개 홈페이지 초안

## 최종 전달 링크

- 케이지에프 소개 홈페이지: https://kclock-boop.github.io/kgf/

이 저장소는 2026년 9월 2일(수) 예정 `(주)케이지에프 AI 훈련컨설팅`을 위해 정리한 검토용 자료 모음입니다. 사전 수준진단 결과 `26점 / Level 1`을 반영해, AI 사용 보안과 데이터 기준을 먼저 정비한 뒤 작은 실무 과제로 검증하는 흐름으로 보완했습니다.

`sammok` 저장소 구성을 참고하되, 케이지에프의 사업 특성에 맞춰 `생산`, `품질`, `공정 최적화`, `재고/계획`, `R&D` 중심으로 재구성했습니다.

## 컨설팅에서 바로 쓸 수 있는 핵심 메시지

1. 케이지에프는 소재 제조와 품질 관리, R&D 확장성이 분명한 회사이므로 `현장 안전형 AI`보다 `생산·품질 운영형 AI`가 더 자연스럽습니다.
2. 사업 참여신청서상 현재 AI 활용 성숙도는 초기 단계이므로, 전사 플랫폼보다 `생산/품질 부서의 반복 업무 자동화`부터 시작하는 편이 좋습니다.
3. 초기 우선영역은 `AI 사용 보안`, `품질 데이터 정리`, `불량 이슈 분류`, `보고 자동화`, `AI 리더 육성`입니다.
4. 결과분석 자료의 공정 예시는 KGF 공식 사업 정보와 일치 여부를 확인하지 못했으므로, 특정 설비·공정의 사실로 쓰지 않고 현장 확인 항목으로만 다룹니다.
4. 대시보드는 완성 시스템 소개가 아니라, `무엇을 질문하고 어떤 데이터를 먼저 모아야 하는지`를 보여주는 운영 시안 역할로 활용하면 좋습니다.
