- 권장 방향: `AX 입문 및 보안 체계 정비`
- 우선 보완: AI 이해도 및 활용, AI 데이터 보안, 노코드 데이터 분석, 데이터 검증, 실행 책임체계
- 실행 순서: 보안 가이드와 공용 양식 정비 → 반복 문서 자동화 실습 → 제한된 파일럿 검증

## 이번 컨설팅에서 안전하게 활용할 수 있는 표현

- 케이지에프의 생산·품질 운영 특성을 반영한 AI 훈련컨설팅
- 품질 데이터 기반의 업무 자동화와 공정 최적화 검토
- 생산계획 및 재고 관리의 가시성 향상
- 부서 단위 MVP에서 시작하는 AI 적용 전략

## 현장 확인이 필요한 항목

- 실제로 활용 가능한 데이터 파일 형식
- 품질 데이터의 누적 기간과 상세 컬럼
- 생산계획/재고 관리의 현재 주기
- 부서별 실무 리더 또는 AI 확산 담당 후보
- 외부 공유 가능한 회사소개 문구 범위

## 권장 사용 원칙

1. 전면 페이지는 공식 홈페이지 기준 정보를 중심으로 두고, 컨설팅 해석은 별도 제안 문장으로 분리합니다.
2. 자가진단표는 기업 상태를 단정하는 문서가 아니라, `우선순위를 좁히는 자료`로만 사용합니다.
3. 불량률, 계획 차질, 재고 이슈 같은 구체 수치는 현장 데이터 확인 전까지 예시 수준으로만 제시합니다.
4. 결과분석 문서에 포함된 `모터 성능 검사`, `프레스/조립` 등은 KGF 공식 사업 정보와 일치 여부를 확인하지 못했으므로, KGF의 사실 또는 확정 과제로 사용하지 않습니다. 현장 확인 질문으로만 다룹니다.
