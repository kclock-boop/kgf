# AI컨설팅 자료실

케이지에프 AI 훈련컨설팅에서 검토·공유하는 산출물을 모아두는 자료실입니다.

## 현재 자료

| 자료 | 용도 |
|---|---|
| [AI 실행 전략 (PDF)](./케이지에프_AI_실행전략.pdf) | 생성형 AI와 제조 AI를 생산·품질·R&D 업무에 단계적으로 적용하기 위한 7장 전략 자료 |
| [노코드용 프롬프트 10선 (PDF)](./케이지에프_노코드용_프롬프트_10선.pdf) | 생산·품질·현장업무 웹보드 기획과 노코드 앱 제작에 바로 쓰는 프롬프트 모음 |
| [AI 훈련로드맵 사전 수준진단 결과분석 (PDF)](./케이지에프_AI_수준진단_결과분석.pdf) | KGF AI 수준진단 26점 / Level 1을 바탕으로 현장 확인 질문과 우선 훈련과제를 정리한 발표용 자료 |
| [현장업무 자동화·통합대시보드·자료실 구축계획서 (PDF)](./케이지에프_현장업무자동화_통합대시보드_자료실_구축계획서.pdf) | 품질·생산·시험/검사·계획 자료를 공용 기준으로 연결하는 PoC 계획서 |
| [현장업무 자동화·통합대시보드·자료실 구축계획서 (수정용 원본)](./케이지에프_현장업무자동화_통합대시보드_자료실_구축계획서.md) | 현장 인터뷰 결과에 따라 문구와 범위를 조정할 수 있는 원본 |

## 활용 원칙

- 본 자료는 사전 수준진단 `26점 / Level 1`과 현재 확인된 자료를 바탕으로 한 컨설팅 초안입니다.
- 자료 안의 구체 공정, 시스템, 데이터 범위는 현장 확인 후 확정합니다.
- AI 사용 시 민감정보·고객정보·단가·기술정보의 외부 입력 여부는 사내 기준과 담당자 검토를 거칩니다.
