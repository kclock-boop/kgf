# 케이지에프 현장업무 자동화·통합대시보드·자료실 구축계획서

작성일: 2026-09-01  
구축 단계: PoC 기획안  
적용 기준: 사전 수준진단 26점 / Level 1

## 1. 추진 개요

### 핵심 방향

생산·품질·시험/검사·생산계획 관련 자료가 담당자별 파일, 보고서, 시스템 등 여러 위치에 있을 수 있다는 전제에서, **공용 양식과 자료 분류체계**를 먼저 정리한다. 이후 품질 이슈와 보고 업무를 중심으로 `자료실 → 상태관리 → 대시보드 → 보고 자동화`를 작은 범위부터 검증한다.

### 추진 배경

- 케이지에프는 생산·품질 부서를 AI 집중 코칭 대상으로 제시했고, 품질 데이터 보유 가능성을 확인했다.
- 사전 수준진단은 26점 / Level 1으로, AI 사용 보안과 데이터 관리·검증 기준을 함께 정비하는 접근이 필요하다.
- 품질 이슈, 시정조치, 시험/검사 결과, 생산계획·재고 관련 보고는 반복 집계와 설명 작성 업무가 발생할 가능성이 높다.
- 실제 업무 채널, 보유 시스템, 자료 위치는 현장 인터뷰와 샘플 양식 확인 후 확정한다.

### 구축 목표

| 구분 | 현재 확인·점검 범위 | PoC 목표 | 기대효과 |
|---|---|---|---|
| 자료관리 | 파일 위치·양식·책임자 현황 확인 | 품질·시험·생산 관련 자료의 공용 분류체계 | 검색·재사용·검토 시간 단축 |
| 이슈관리 | 불량·조치·검토 흐름 확인 | 이슈번호 기반 상태·조치이력 관리 | 누락 방지·원인 추적 |
| 대시보드 | 관리자가 보는 핵심 질문 확인 | 품질·계획·보고용 요약 화면 | 우선순위 판단 지원 |
| 보고자동화 | 반복 보고서 유형 확인 | 주간 보고·회의자료 초안 생성 | 취합·작성 시간 절감 |
| AI 사용기준 | 입력 가능 정보·검토자 확인 | 보안 가이드와 검토 절차 적용 | 안전한 실무 활용 |

## 2. 현행 업무 분석 및 확인 과제

### As-Is 확인 흐름

품질/생산 자료 발생 → 담당자별 저장 또는 보고 → 수기·엑셀·시스템 자료 취합 → 회의 또는 보고서 작성 → 조치 요청·검토 → 완료 확인

### 현장 확인이 필요한 병목

| 확인 항목 | 확인 질문 | PoC 설계 반영 |
|---|---|---|
| 자료 위치 | 품질·시험·생산계획 자료는 어디에 저장되는가 | 자료실 연결 방식 |
| 이슈 흐름 | 불량·클레임·시정조치는 어떤 번호와 상태로 관리되는가 | 상태값과 이력 구조 |
| 보고 업무 | 매주 반복되는 취합·회의자료는 무엇인가 | 자동화 우선 과제 |
| 데이터 책임 | 누가 입력하고 누가 검토·승인하는가 | 권한·검토 절차 |
| 보안 기준 | 외부 AI 입력 금지 정보는 무엇인가 | 마스킹·사용 가이드 |

> 주의: 메신저, 도면, 설비 로그 등 구체적인 현행 방식은 KGF에서 확인된 사실이 아니므로 본 계획서에서는 확정 전제로 사용하지 않는다.

## 3. 목표 시스템(To-Be) 개념

### 통합 구조

`공용 자료실(Data Room)` → `품질·생산 이슈 관리` → `통합 대시보드` → `주간 보고·회의자료 자동화`

### 표준 업무 프로세스

자료/이슈 등록 → 담당자 확인 → 사실·원인·조치 입력 → 검토 요청 → 조치 완료 → 승인 또는 보완 요청 → 이력 저장 → 대시보드·보고 반영

### 상태값 초안

| 상태 | 의미 | 담당자 행동 |
|---|---|---|
| 등록 | 자료 또는 이슈가 새로 접수됨 | 기본정보·분류 입력 |
| 확인 | 담당 부서가 내용을 인지함 | 담당자·기한 지정 |
| 조치중 | 원인 확인 또는 개선 활동 진행 | 조치내용·증빙 추가 |
| 검토대기 | 조치 완료 후 검토 요청 | 검토자 확인 |
| 승인 | 검토가 완료됨 | 이력 확정 |
| 보완요청 | 추가 확인 또는 재조치 필요 | 보완 사유·기한 기록 |

## 4. PoC 기능 계획

### 관리자·실무자 공통 기능

- 품질 이슈, 시험/검사 결과, 생산계획 관련 자료의 등록·분류·검색
- 이슈번호별 원인, 조치, 검토상태, 관련 파일을 한 화면에서 연결
- 지연·검토대기·반복 이슈를 자동 분류해 관리자에게 표시
- 일일·주간 품질·계획 보고의 초안과 회의용 요약 생성
- AI 사용 전 마스킹 여부와 최종 검토 책임자를 기록

### 사용자별 화면

| 사용자 | 주요 질문 | 우선 화면 |
|---|---|---|
| 경영진 | 이번 주 어떤 품질·납기 이슈를 먼저 봐야 하는가 | 핵심 이슈·조치·지연 요약 |
| 생산 관리자 | 계획 대비 실적과 지연 사유는 무엇인가 | 계획·실적·지연 현황 |
| 품질 관리자 | 반복 이슈와 미완료 조치는 무엇인가 | 이슈·시정조치·검토대기 현황 |
| 실무 담당자 | 내가 처리할 자료와 조치는 무엇인가 | 내 할 일·자료 등록·조치 입력 |
| 데이터/보안 담당 | 어떤 자료가 AI에 사용됐고 검토됐는가 | 마스킹·검토·권한 기록 |

## 5. Data Room(자료실) 구축 계획

### 자료실 분류체계 초안

| 자료실 | 우선 대상 자료 | 현장 확인 후 확정할 사항 |
|---|---|---|
| 품질 자료실 | 불량 이력, 시정조치, 클레임, 품질 기준 | 실제 불량 분류·승인 양식 |
| 시험/검사 자료실 | 시험성적서, 검사 결과, 판정 기록 | 제품군별 필수 항목 |
| 생산·계획 자료실 | 생산계획, 실적, 납기 이슈 | 계획 수립·변경 주기 |
| 재고 자료실 | 재고 현황, 부족·과다 이슈 | 공유 가능 범위·기준 |
| R&D·기술 자료실 | 시험 요약, 기술 검토 문서 | 보안 등급·외부 반출 기준 |
| 보고 자료실 | 주간 보고, 회의자료, 승인본 | 보관 주기·최종본 기준 |

### 핵심 데이터 필드

`이슈/자료번호`, `제품군`, `부서`, `공정 또는 업무구분`, `자료유형`, `발생일`, `등록자`, `검토자`, `상태`, `원인분류`, `조치내용`, `기한`, `보안등급`, `AI 입력 가능 여부`, `파일명`, `버전`

### 자료관리 원칙

1. 모든 자료는 번호와 기본 분류값으로 연결한다.
2. 파일명만으로 찾지 않고 제품군·유형·일자·상태로 검색 가능하게 설계한다.
3. AI 입력 전에는 민감정보·고객정보·단가·기술정보를 확인하고 필요 시 마스킹한다.
4. AI가 만든 요약·초안은 원본 대조와 담당자 검토 후 활용한다.

## 7. 자동화 규칙 및 AI 확장 계획

### 우선 자동화 규칙

| 자동화 항목 | 처리 규칙 |
|---|---|
| 상태 집계 | 등록·확인·조치중·검토대기·승인·보완요청 상태를 자동 집계 |
| 기한 표시 | 검토 또는 조치 기한이 지나면 지연 후보로 표시 |
| 자료 연결 | 파일을 이슈/자료번호와 분류값에 연결 |
| 보고 초안 | 승인된 자료 기준으로 주간 요약·회의자료 초안 생성 |
| 반복 이슈 | 동일 제품군·유형·원인 키워드의 반복 후보를 표시 |

### AI 적용 순서

1. AI 사용 보안 가이드와 결과 검토 책임을 정한다.
2. 마스킹된 샘플 자료로 요약·분류·보고 초안을 실습한다.
3. 품질 이슈 또는 생산계획 보고 중 한 가지를 제한된 범위에서 파일럿한다.
4. 정확도, 재작업, 시간 절감, 보안 준수 여부를 점검한다.
5. 충분한 데이터가 쌓인 후 유사사례 검색·패턴 탐색·이미지 분석 가능성을 검토한다.

## 11. 최종 제안

> “케이지에프의 품질·생산·시험/검사·계획 관련 자료를 공용 분류체계로 연결하고, 이슈 상태와 검토 이력을 한 화면에서 확인하며, 검증 가능한 반복 보고 업무부터 자동화하는 PoC를 추진한다.”

초기 PoC는 `공용 양식 + 자료실 분류 + 이슈 상태관리 + 요약 대시보드 + 보고 초안`에 집중한다. 실제 시스템 연동, 이미지 분석, 고도화 AI 기능은 데이터 품질과 보안·검토 절차가 자리잡은 뒤 단계적으로 검토한다.
